# Traval — Project Action Plan (Revised)

**โครงการ:** Traval — Travel & Local Discovery Platform  
**ทีม:** Moo / Nine / Tommy / Prom  
**ระยะเวลา:** 10 สัปดาห์ (แผนเบื้องต้น)  
**Week 1–2:** Research & Planning  
**Week 3–10:** Design / Development / Integration / Testing

---

## 1. หน้าที่และความรับผิดชอบ

| ผู้รับผิดชอบ | หน้าที่ |
|---|---|
| **Moo** | UX/UI Design — User / Home / Discover / Map / Real-Time Location / Local SME |
| **Nine** | UX/UI Design — Admin / Business / My Trips / Login / Register |
| **Tommy** | ศึกษา Google Services / Support ทีมพัฒนา / Integration / Tester / ตรวจสอบงานตกหล่น |
| **Prom** | Backend Development / Database / API / System Architecture / Integration / Frontend Testing |

---

# 2. Action Plan รายบุคคล

## Moo — UX/UI Design (User / Map)

### Week 1–2: Research & Planning

**Week 1 — ศึกษาและวิเคราะห์**

- ศึกษา UX/UI ของแพลตฟอร์มท่องเที่ยว เช่น Google Maps, Wongnai, Tripadvisor
- ศึกษารูปแบบหน้า Home / Discover / Search
- ศึกษาการแสดงข้อมูลสถานที่ท่องเที่ยวและร้าน Local SME
- ศึกษาการออกแบบ Map และ Real-Time Location
- ศึกษารูปแบบ Nearby Places / Around Me
- วิเคราะห์จุดเด่น ข้อจำกัด และแนวทางที่สามารถนำมาปรับใช้กับ Traval

**Week 2 — วางแนวทางการออกแบบ**

- กำหนด User Flow ของหน้า User / Map
- วางโครงสร้างเมนูและการนำทาง
- จัดทำ Wireframe เบื้องต้น
- กำหนดแนวทาง Design System / สี / Typography / Components
- วางรูปแบบการแสดงร้าน SME และ Local Spotlight
- สรุปแนวทาง UI/UX เพื่อนำเสนอทีม

### Week 3–10: Design & Support

- W3–4: ออกแบบ Home / Discover / Search / Place Detail
- W4–5: ออกแบบ Map / GPS / Around Me / SME Spotlight / Collection
- W6: Responsive Design / Interactive Prototype
- W7–8: ส่งมอบ Design และสนับสนุน Frontend Integration
- W9–10: ตรวจสอบ UI / แก้ไขรายละเอียด / Final Design

**Deliverables**
- UX Research Summary
- User Flow / Wireframe
- Figma Design
- Interactive Prototype
- Design Handoff

---

## Nine — UX/UI Design (Admin / Business / Trips / Login)

### Week 1–2: Research & Planning

**Week 1 — ศึกษาและวิเคราะห์**

- ศึกษารูปแบบ Login / Register และ Social Login
- ศึกษาระบบ Admin Dashboard และ CMS
- ศึกษาระบบจัดการผู้ใช้งานและสถานที่
- ศึกษาระบบ Business Registration สำหรับ SME
- ศึกษาระบบโปรโมตร้านค้าและ Sponsored Listings
- ศึกษารูปแบบ Trip Planner / Itinerary ของแพลตฟอร์มท่องเที่ยว

**Week 2 — วางโครงสร้างระบบ**

- กำหนด User Flow ของ Login / Register
- วางโครงสร้าง Admin / Business Dashboard
- วางระบบสมัครร้านค้าและจัดการข้อมูลร้าน
- วาง Flow การซื้อแพ็กเกจโปรโมตและการอนุมัติ
- วางโครงสร้าง My Trips แบบ Manual / Auto
- จัดทำ Wireframe หน้าหลัก
- ประสานงานกับ Moo เพื่อใช้ Design System เดียวกัน

### Week 3–10: Design & Support

- W3–4: ออกแบบ Login / Register / Admin Dashboard / CMS
- W4–5: ออกแบบ Business Registration / Shop Profile / Promotion
- W5–6: ออกแบบ My Trips / Route / Budget / AI Advisor
- W7–8: Prototype / Design Handoff / Integration Support
- W9–10: ตรวจสอบ UX/UI และเก็บรายละเอียด

**Deliverables**
- UX Research Summary
- Authentication / Admin / Business / Trip User Flow
- Wireframe
- Figma Design
- Interactive Prototype

## Tommy — Google Integration / Support / Tester

### Week 1–2: Research & Technical Study

**Week 1 — ศึกษาระบบ Google**

- ศึกษา Google Maps Platform
- ศึกษา Maps JavaScript API
- ศึกษา Places API
- ศึกษา Routes API
- ศึกษา Browser Geolocation / Real-Time GPS
- ศึกษา Google Authentication
- ศึกษาค่าใช้จ่าย Quota และข้อจำกัดของ Google API

**Week 2 — ศึกษาการเชื่อมต่อและทดสอบเบื้องต้น**

- ศึกษาวิธีปักหมุดร้านบน Traval
- ศึกษาการเชื่อมต่อ Google Place ID
- ศึกษา Google Business Profile สำหรับ SME ที่ยังไม่มีร้านบน Google Maps
- ศึกษาการคำนวณระยะทางและเวลาเดินทาง
- ทดลอง Proof of Concept สำหรับ Map / GPS / Places
- สรุปข้อจำกัดและความเป็นไปได้
- ประสานงานกับ Prom เพื่อกำหนดแนวทาง Integration

### Week 3–10: Integration & Testing

- W3–4: Google API Setup / Maps / Places / Routes Integration
- W5–6: Support Backend–Frontend / Google Login / GPS
- W7–8: Integration Testing / ตรวจสอบงานตกหล่น / แก้ไข Bug
- W9: End-to-End Testing / Regression Testing
- W10: Final QA / Release Support

**Deliverables**
- Google API Research Report
- Google Maps Proof of Concept
- Integration Test Report
- Bug Tracking / Bug Fix Report
- Final QA Report

---

## Prom — Backend / Database / System Integration

### Week 1–2: Research & System Planning

**Week 1 — ศึกษาและวิเคราะห์โครงสร้างระบบ**

- ศึกษา Requirement ของ Traval ทั้งหมด
- วิเคราะห์การทำงานของ USER / ADMIN / BUSINESS
- ศึกษาเทคโนโลยีสำหรับ Backend
- ศึกษาการจัดการ Database และข้อมูลพิกัด
- ศึกษาระบบ Authentication / Authorization
- ศึกษาการเชื่อมต่อ Google APIs
- ศึกษารูปแบบการจัดเก็บข้อมูลสถานที่ ร้านค้า รีวิว และทริป
- วิเคราะห์ความปลอดภัยและการจัดการข้อมูลส่วนบุคคล

**Week 2 — วางระบบและโครงสร้างการพัฒนา**

- ออกแบบ System Architecture
- ออกแบบ Database Schema / ER Diagram
- กำหนดโครงสร้าง Backend API
- กำหนด Role / Permission
- วางโครงสร้างข้อมูล USER / PLACE / SME / REVIEW / TRIP
- วางระบบ Business Registration / Promotion / Payment
- กำหนด API Contract เพื่อใช้เชื่อมต่อ Frontend
- ศึกษาการ Deploy / Hosting / File Storage
- สรุปเครื่องมือและโครงสร้างเทคโนโลยีที่จะใช้พัฒนา

### Week 3–10: Backend Development

- W3: Project Setup / Database / Authentication
- W4: User / Profile / Places / Categories API
- W5: Search / Nearby / SME / Collection / Reviews API
- W6: Admin / Business Registration / Shop Management API
- W7: My Trips / Routes / Budget / Promotion พื้นฐาน
- W8: Frontend–Backend Integration / Support Tommy
- W9: API Testing / Security / Performance / Bug Fix
- W10: Deploy / Final Testing / Documentation

**Deliverables**
- Technical Research / System Architecture
- Database Schema / Migration
- Backend API
- API Documentation
- Integration Test Report
- ระบบ MVP บนสภาพแวดล้อมทดสอบ

# 6. เป้าหมายของโครงการ

**Research Phase (Week 1–2)**
- ทุกคนเข้าใจภาพรวมและหน้าที่ของตัวเอง
- มีแนวทาง UX/UI ที่ชัดเจน
- มีโครงสร้าง Backend และ Database ที่ตกลงร่วมกัน
- ทราบความเป็นไปได้และข้อจำกัดของ Google Maps Integration

**Development Phase (Week 3–10)**
- มี Traval MVP ที่สามารถทดลองใช้งานได้
- ผู้ใช้ค้นหาสถานที่และร้าน SME ได้
- Map แสดงตำแหน่งปัจจุบันและสถานที่รอบตัวได้
- ผู้ใช้สร้างและจัดการทริปเบื้องต้นได้
- Business สมัครและจัดการข้อมูลร้านพื้นฐานได้
- Admin สามารถตรวจสอบและจัดการข้อมูลได้
- Backend / Frontend / Database เชื่อมต่อกันได้
- มีการทดสอบและแก้ไขปัญหาก่อน Demo

**หมายเหตุ:** แผนนี้เป็นระยะเวลาเป้าหมายเบื้องต้น การพัฒนา AI ขั้นสูง ระบบจ่ายเงินซื้อโฆษณาจริง และ Business Analytics เต็มรูปแบบอาจแยกออกเป็นระยะถัดไปตามผลการศึกษาและทรัพยากรของทีม
