# อ่านก่อนทำต่อ — unfold / Traval

เอกสารความต้องการฉบับเต็มอยู่ที่ `Traval_Requirements_Business_Updated.txt` (ชื่อผลิตภัณฑ์ในสเปกคือ **Traval** โค้ดที่รันอยู่ชื่อ **unfold v2.7**)

งานนี้ยังไม่ครบสเปกทั้ง 3 เฟส โฟลเดอร์ถูกจัดตาม Role ในสเปก เพื่อให้แก้ถูกที่และไม่ทับของคนอื่น

งาน Backend ของ Prom วันที่ 19 ตุลาคม 2026 อยู่ในไฟล์เดียว: `docs/prom-backend-week1-2-2026-10-19.md`

## เริ่มยังไง

1. ติดตั้ง Node.js 24 LTS (ขั้นต่ำ 22.16)
2. ดับเบิลคลิก `START-WINDOWS.cmd` ที่รากโปรเจกต์ ห้ามเปิดไฟล์ HTML ผ่าน `file://`
3. เปิด `http://127.0.0.1:5173/`
4. ก่อนส่งงานรัน `npm test` ในโฟลเดอร์นี้

URL ไม่เปลี่ยนหลังย้ายไฟล์ เซิร์ฟเวอร์ใน `server.js` แมป URL ไปที่ไฟล์จริงผ่าน `PAGE_FILES`

| เปิดในเบราว์เซอร์ | ไฟล์ที่แก้ |
|---|---|
| `/` นักท่องเที่ยว | `apps/traveler/` |
| `/planner.html` วางแผนทริป | `apps/planner/` |
| `/admin.html` `/moderation.html` `/audit.html` | `apps/admin/` |
| `/business.html` `/business-admin.html` | `apps/business/` |
| API และฐานข้อมูล | `server.js` |
| คำนวณระยะทางทริป | `apps/planner/trip-engine.js` |
| รูปไอคอนและภาพตัวอย่าง | `assets/` |
| สำรอง / กู้คืน / ตรวจฐานข้อมูล | `backup.js` `restore.js` `doctor.js` และไฟล์ `*-WINDOWS.cmd` |
| ทดสอบอัตโนมัติ | `tests/*.test.js` |

ข้อมูลจริงของเครื่องนี้อยู่ที่ `%LOCALAPPDATA%\unfold-travel\data\` ไม่ได้อยู่ในโฟลเดอร์โค้ด

## กติกาเวลาแก้

- เพิ่มคอลัมน์หรือตารางใน SQLite แบบเพิ่มอย่างเดียว อย่าเขียนคำสั่งที่ลบข้อมูลผู้ใช้ตอนเซิร์ฟเวอร์เริ่ม
- อย่าใส่ยอดรีวิว รายได้ หรือสถิติที่ไม่มีในฐานข้อมูล
- อย่าเปลี่ยน URL สาธารณะ ถ้าเพิ่มหน้าใหม่ ให้ใส่คู่ URL → ไฟล์ใน `PAGE_FILES` ของ `server.js`
- ไฟล์ HTML อ้าง `styles.css` และ `assets/...` แบบชื่อสั้นได้ เพราะเบราว์เซอร์ขอจากรากเว็บ ไม่ใช่จากโฟลเดอร์ `apps/`
- สเปกระบุ Google Maps, ล็อกอิน Google/Facebook/เบอร์โทร, AI จริง และการจ่ายเงินไว้เป็นเฟสถัดไป อย่าต่อคีย์หรือเกตเวย์ชำระเงินจนกว่าจะมีงานนั้นชัดเจน
- ร้านค้าสมัครและซื้อโฆษณาเองเป็น Phase 3 ช่วงนี้ Admin เป็นคนจัดการร้านและโปรโมต

สไตล์ของแต่ละหน้าอยู่คู่กับ HTML ในโฟลเดอร์เดียวกัน เช่น `apps/admin/audit.css` คู่กับ `audit.html`

## สถานะเทียบสเปก

| ข้อในสเปก | สถานะ | ไปแก้ที่ |

| 1.1 Home / Discover ค้นหา หมวดหมู่ ภาษาไทย/อังกฤษ กดหัวใจ | มีแล้ว | `apps/traveler/app.js` `styles.css` |

## ลำดับที่ควรทำต่อ

ทำทีละข้อแล้วรัน `npm test` ก่อนขึ้นข้อถัดไป

1. **Phase 1 ที่ยังขาดบนหน้านักท่องเที่ยว:** โซน Local SME, ตัวกรอง Local Only, รัศมี Around Me ตามสเปก (300 ม. ถึง 5 กม.), Search This Area
2. **Phase 1 แผนที่:** จุด You Are Here, ปุ่ม My Location, หยุด Follow Me เมื่อผู้ใช้เลื่อนแผนที่
3. **Phase 1 คอลเลกชัน:** แยกกล่องบันทึกตามจังหวัดหรือหมวดได้
4. **Phase 2:** Travel Safety ที่ Admin ต้องอนุมัติก่อนโชว์, แล้วค่อยทำ AI จากข้อมูลสถานที่จริงในฐานข้อมูล
5. **Phase 3:** สมัครร้านเองแบบครบ, ปักหมุด, ค่อยต่อแพ็กเกจ Sponsored และเกตเวย์ชำระเงิน

สเปกระบุว่า Phase 1–2 ให้ Admin จัดการร้านแทนเจ้าของ และของที่มีอยู่ตอนนี้เดินตามนั้นแล้ว
