# หน้าร้าน SME (Shop pages) — คู่มือทีม

> เจ้าของ: Tommy · เพิ่มเมื่อ 2026-11-06 · อ่านไฟล์นี้ก่อนแก้ `backend/shop-pages.js`, `frontend/shared/shop-render.*`, `frontend/shop/*`, `frontend/business/shop-editor.*`, `frontend/admin/admin-shop-pages.js`

## ภาพรวม

ร้าน SME ที่อยู่บนแผนที่ Traval มี **หน้าร้าน** ของตัวเองได้ นักท่องเที่ยวเปิดจากปุ่ม "🏪 ดูหน้าร้าน" ในหน้าสถานที่ หรือในแผ่นข้อมูลบนแผนที่ ลิงก์ของหน้าร้านคือ `/shop/<place id>` ซึ่งแชร์ต่อได้

เจ้าของร้านออกแบบหน้าร้านเองในแท็บ **Business portal → หน้าร้านของฉัน** โดยเลือกแม่แบบและสี แล้วเติมข้อมูลทีละส่วน มีตัวอย่างแบบมือถือให้ดูทันทีที่แก้

| ใคร | เห็น / ทำอะไรได้ |
|---|---|
| นักท่องเที่ยว | หน้าร้านที่เผยแพร่แล้ว: นำทาง (Google Maps), รีวิวบน Traval + ปุ่มเขียนรีวิวในแอป, "รีวิวบน Google" (เฉพาะร้านที่ใส่ลิงก์ไว้), แชร์ |
| เจ้าของร้าน | สร้าง/แก้หน้าร้าน, ดูตัวอย่าง, ส่งตรวจ (ครั้งแรก), เผยแพร่การแก้ไข (ครั้งต่อไป) |
| แอดมิน | อนุมัติ / ส่งกลับ (ต้องใส่เหตุผล) หน้าร้านครั้งแรก, ดูตัวอย่าง, ซ่อนหน้าร้านได้ทุกเมื่อ |

## กฎการอนุมัติ (ทีมตัดสินใจ 2026-11-06)

1. หน้าร้าน **ครั้งแรก** → `pending` → แอดมินอนุมัติ → `approved` (ขึ้นหน้าจริง)
2. หลังเคยอนุมัติแล้ว เจ้าของกด "เผยแพร่การแก้ไข" → **ขึ้นทันที** ไม่ต้องรอแอดมิน (`shop_page.publish` ใน audit log)
3. แอดมินกด "ซ่อน" → `hidden` (หน้าหายจากสาธารณะ) → เจ้าของแก้แล้วส่งใหม่ → `pending` เหมือนครั้งแรก
4. ส่งกลับ (`rejected`) ต้องมีเหตุผลเสมอ เจ้าของเห็นข้อความนั้นใน editor
5. ถ้าในอนาคตจะไม่ต้องอนุมัติครั้งแรกด้วย ให้ตั้ง `TRAVAL_SHOP_PAGES_AUTO_APPROVE=1`

สถานะ: `draft` (ยังไม่เคยเผยแพร่) · `pending` · `approved` (มีหน้าจริง; `hasChanges` = มีร่างที่ยังไม่เผยแพร่) · `rejected` · `hidden`

## ปุ่ม Google

- **รีวิวบน Traval** แสดงเสมอ และใช้ระบบรีวิวเดิม (`/api/places/:id/reviews`)
- **รีวิวบน Google** เป็นแค่ลิงก์ไปหน้า Google Maps เราไม่ได้ดึงรีวิวของ Google มาแสดง จึงไม่มีค่าใช้จ่าย
  - ถ้าร้านมีหน้าร้านบน Traval ปุ่มจะขึ้นก็ต่อเมื่อเจ้าของใส่ลิงก์ Google Maps (`google.url`) หรือ Place ID ไว้แล้วเท่านั้น
  - ถ้าเป็นร้าน SME (`isSme`) ที่ไม่มี `googlePlaceId` จะไม่มีปุ่มนี้
  - สถานที่ทั่วไปที่ไม่ใช่ SME ใช้วิธีเดิม คือค้นชื่อสถานที่ใน Google Maps
- ถ้ามี Place ID ในหน้าร้านที่เผยแพร่ ระบบจะบันทึกลง `places.google_place_id` ด้วย ทุกปุ่ม Google ในแอปจึงใช้ค่าเดียวกัน

## ข้อมูลหน้าร้าน (เก็บเป็น JSON ใน `shop_pages.draft_json` / `published_json`)

```json
{
  "template": "classic | modern | market",
  "color": "forest | sunset | ocean | berry | charcoal",
  "google": { "url": "https://maps.app.goo.gl/…", "placeId": "" },
  "sections": [
    { "type": "hero",    "visible": true, "title": "", "subtitle": "", "image": "/uploads/<uuid>.webp" },
    { "type": "story",   "heading": "", "text": "" },
    { "type": "menu",    "heading": "", "items": [{ "name": "", "price": 65, "description": "", "image": "" }] },
    { "type": "gallery", "heading": "", "images": ["/uploads/…"] },
    { "type": "hours",   "heading": "", "lines": [{ "days": "จันทร์–ศุกร์", "time": "08:00–17:00" }], "note": "" },
    { "type": "promo",   "title": "", "text": "", "validUntil": "2026-12-31" },
    { "type": "contact", "heading": "", "phone": "", "line": "@id", "facebook": "", "instagram": "", "tiktok": "", "website": "" }
  ]
}
```

ข้อจำกัดของข้อมูล:
- หน้าร้านมีได้ไม่เกิน 12 ส่วน
- เมนูไม่เกิน 40 รายการ
- รูปในแกลเลอรีไม่เกิน 12 รูป
- เวลาเปิด–ปิดไม่เกิน 14 บรรทัด
- ข้อมูลทั้งหน้าไม่เกิน 200 KB

ครั้งแรกที่เปิด editor ระบบจะสร้างร่างเริ่มต้นให้จากข้อมูลสถานที่ที่มีอยู่แล้ว ได้แก่ ชื่อ, รูปปก, เรื่องราว และเบอร์โทร

## ความปลอดภัย (ห้ามทำให้ข้อใดข้อหนึ่งหายไป)

- **ไม่มี HTML จากเจ้าของร้าน** เจ้าของกรอกได้เฉพาะข้อความในช่องที่กำหนด `shop-render.js` จะ escape ข้อความทุกตัวก่อนแสดง
- **รูป** ต้องเป็น path `/uploads/<uuid>.(webp|png|jpg)` และต้องเป็นรูปที่ธุรกิจนั้นอัปโหลดเอง (`business_media`) หรือเป็นรูปที่อยู่ในสถานที่นั้นอยู่แล้ว
- **ลิงก์ทั้งหมด** ต้องเป็น `https://` เท่านั้น
  - Facebook, Instagram, TikTok และ LINE ต้องเป็นโดเมนของบริการนั้นจริง
  - ลิงก์ Google ต้องเป็น `google.*/maps`, `maps.app.goo.gl` หรือ `goo.gl`
- **คนที่แก้ได้:** ต้องเป็นธุรกิจที่อนุมัติแล้ว และผูกกับสถานที่ใน `place_owners`
- **รูปที่ยังไม่เผยแพร่** ยังเป็นส่วนตัว พอหน้าร้านเผยแพร่แล้ว รูปที่ใช้ในหน้านั้นจึงเปิดดูได้สาธารณะ (ดูส่วน `/uploads/` ใน `server.js`)
- **คุกกี้แอดมิน** ส่งไปเฉพาะ `/api/admin` เท่านั้น ตัวอย่างหน้าร้านในฝั่งแอดมินจึงต้องโหลดรูปผ่าน `/api/admin/business-media/<file>`

## API

| เมธอด | เส้นทาง | ใคร | ทำอะไร |
|---|---|---|---|
| GET | `/api/shop-pages` | ทุกคน | รายชื่อสถานที่ที่มีหน้าร้าน `[{id, googleUrl}]` (แอปโหลดตอนเริ่ม) |
| GET | `/api/shop-pages/:id` | ทุกคน | หน้าร้านที่เผยแพร่แล้ว `{page, place, googleUrl}` |
| GET | `/api/shop-pages/:id?draft=1` | เจ้าของ | ร่าง (ตัวอย่าง) |
| GET | `/api/business/shop-pages` | เจ้าของ | สถานที่ของฉัน + หน้าร้าน (มีร่างเริ่มต้นให้) |
| PUT | `/api/business/shop-pages/:id` | เจ้าของ | บันทึกร่าง `{content}` |
| POST | `/api/business/shop-pages/:id/submit` | เจ้าของ | ครั้งแรก → รออนุมัติ / หลังจากนั้น → เผยแพร่ทันที · ตอบ `{page, published}` |
| GET | `/api/admin/shop-pages?status=pending\|approved\|rejected\|hidden\|draft\|all` | แอดมิน | รายการ |
| GET | `/api/admin/shop-pages/:id` | แอดมิน | ร่าง + ฉบับที่เผยแพร่อยู่ (`live`) |
| POST | `/api/admin/shop-pages/:id/decision` | แอดมิน | `{status: approved\|rejected, note}` |
| POST | `/api/admin/shop-pages/:id/unpublish` | แอดมิน | ซ่อน `{note}` |

## ยังไม่ได้ทำ (ไอเดียต่อ)

- ตั้งชื่อลิงก์เองแบบ `/shop/baan-coffee` (ตอนนี้ใช้ place id ซึ่งมักเป็นชื่ออังกฤษอยู่แล้ว)
- นับจำนวนคนเปิดหน้าร้านให้เจ้าของดูใน Overview
- แสดงหน้าร้านแบบออฟไลน์ (ตอนนี้ต้องต่อเน็ต)
