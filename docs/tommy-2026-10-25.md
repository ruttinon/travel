## 8. สถานที่ทั่วประเทศไทยจาก OpenStreetMap (เพิ่ม 26 ต.ค.)

แผนที่มี **สถานที่ ~70,000 แห่ง ครบ 77 จังหวัด** (วัด, สถานที่ท่องเที่ยว, พิพิธภัณฑ์, สวน, น้ำตก, ชายหาด, จุดชมวิว, ตลาด, คาเฟ่, ร้านอาหาร, ที่พัก) จาก OpenStreetMap — ฟรี เก็บได้ถาวร (ต้องแสดง © OpenStreetMap contributors ซึ่งแผนที่มีอยู่แล้ว)

| ไฟล์ | หน้าที่ |
|---|---|
| `scripts/osm/build_thailand_places.py` | (ใช้ตอนอัปเดตข้อมูลเท่านั้น) อ่านไฟล์ Geofabrik → คัดสถานที่ที่มีชื่อ + ใส่จังหวัด/ภาค → `thailand-places.ndjson.gz` (~3 MB) |
| `scripts/osm/import_osm_places.js` | นำเข้าไฟล์ข้างบนเป็น `DATA/osm-places.sqlite` (~27 MB, ใช้เวลา ~2 วินาที) |
| `backend/osm-places.js` | API: `GET /api/map/places?bbox=minLon,minLat,maxLon,maxLat&category=&limit=`, `GET /api/map/search?q=&lat=&lon=`, `GET /api/map/osm-status` |
| `tests/osm_places.test.js` | 4 tests |

หลักการ:
- **แยกไฟล์ฐานข้อมูล** (`osm-places.sqlite`) ไม่ปนกับ `unfold.sqlite` ของทีม → backup/doctor.js ไม่เปลี่ยน, อัปเดตรายเดือนแค่แทนที่ไฟล์, ไลเซนส์ ODbL ไม่ปนกับข้อมูล SME ของเรา
- **โหลดตามพื้นที่ที่เห็นบนจอเท่านั้น** (ไม่โหลด 70,000 จุดเข้ามือถือ): ซูมระดับ 10 ขึ้นไป, จำนวนจุดตามขนาดจอ (~60 จุดบนมือถือ), กระจายทั่วจอ, สถานที่น่าสนใจขึ้นก่อน
- จุด OSM เป็น **จุดสีเล็ก** (ส้ม=วัฒนธรรม, เขียว=ธรรมชาติ, ชมพู=อาหาร, ม่วง=ที่พัก) แยกจากหมุดของทีม; กดแล้วเปิดการ์ดสถานที่ปกติ (นำทาง, รีวิว Google, เพิ่มลงทริปได้)
- **ไม่ขึ้นในหน้า Discover/Home** — หน้าเหล่านั้นยังเป็นสถานที่ที่ทีมคัดเอง
- ค้นหาชื่อได้ทั้งไทยและอังกฤษ (SQLite FTS5 trigram, ไม่ต้องลง package เพิ่ม)

ข้อจำกัดตอนนี้:
- สถานที่ OSM ในทริป/ที่บันทึก **เก็บในเครื่องนั้น** (localStorage) — เซิร์ฟเวอร์รับเฉพาะสถานที่ของทีม (`/api/me/collections` ตรวจกับตาราง `places`). ถ้าจะให้ซิงก์ข้ามเครื่อง ต้องให้ Admin "ดึงเข้า" เป็นสถานที่จริง (งานถัดไป)
- ช่องค้นหาในแอปยังค้นเฉพาะสถานที่ของทีม — API ค้นหา OSM พร้อมแล้ว รอเชื่อมกับหน้า search (ของ Moo)
- ไม่มีรูปภาพ/ราคา จาก OSM (การ์ดแสดง "ราคา: ไม่ระบุ")

วิธีใช้บนเครื่อง (Windows):
```
:: ปิดเซิร์ฟเวอร์ก่อน แล้วรันในโฟลเดอร์โปรเจกต์
node scripts\osm\import_osm_places.js
:: หรือดับเบิลคลิก IMPORT-OSM-PLACES-WINDOWS.cmd
:: เปิดเซิร์ฟเวอร์ใหม่ (run.bat / START-WINDOWS.cmd)
```
อัปเดตรายเดือน: ดาวน์โหลด `https://download.geofabrik.de/asia/thailand-latest.osm.pbf` → รัน `build_thailand_places.py` (ต้องมี Python + `pip install osmium shapely`) → รัน import ใหม่

ไฟล์รายการสถานที่ `scripts/osm/thailand-places.ndjson.gz` (3 MB) **อยู่ใน repo แล้ว** — เพื่อนแค่ pull แล้วดับเบิลคลิก `IMPORT-OSM-PLACES-WINDOWS.cmd` (ไฟล์ดิบ .pbf ~330 MB ไม่อยู่ใน Git; ใช้เฉพาะตอนอัปเดตรายเดือน)

แก้เพิ่ม: ถ้าไฟล์ `frontend/shared/*` ไม่ถูกโหลด แอปยังทำงาน (แค่ลากแผนที่ไม่ได้); สถานที่ OSM ไม่แสดง "Open/Closed" (ไม่มีข้อมูล); ตัวนับ "zoom in" อัปเดตทันที; ชิปเส้นทางบนแผนที่อัปเดตทันที

**สิ่งที่ Moo ควรรู้ (พฤติกรรมแผนที่เปลี่ยนโดยตั้งใจ):**
- ล้อเมาส์บนแผนที่ = ซูมแผนที่ (ไม่เลื่อนหน้าเว็บ) และบนมือถือการปัดบนแผนที่ = ลากแผนที่ (ไม่เลื่อนหน้า) — ปกติของแอปแผนที่
- จะ re-render หลังลากเฉพาะเมื่อมีการเลื่อนจริง
- `app.js` ต้องโหลดผ่าน `node server.js` (หรือ run.bat) เพื่อให้ได้ไฟล์ใน `frontend/shared/`

**สิ่งที่ Prom ควรรู้:**
- `restore.js` คืนเฉพาะ `unfold.sqlite` + รูป → หลัง restore ชั้น OSM จะว่าง ให้รัน `IMPORT-OSM-PLACES-WINDOWS.cmd` ใหม่ (ไม่พัง แค่ไม่มีจุด OSM)
- `module.exports` ของ `backend/server.js` เพิ่ม `DATA` (ของเดิมไม่เปลี่ยน)

ผลทดสอบล่าสุด: `npm test` **29/29 ผ่าน**; ทดสอบในเบราว์เซอร์ (มือถือ + คอม) ผ่าน: XSS ไม่ทำงาน, ลาก/ถ่างนิ้ว/ล้อเมาส์, การ์ดเส้นทาง, ทริปที่มีสถานที่ OSM อยู่ครบหลังรีโหลด, Discover ไม่มีจุด OSM

## 11. แผนก่อนเปิดใช้จริง: เส้นทาง + ภาพแผนที่ (ตัดสินใจ 27 ต.ค.)

ตอนนี้ใช้บริการฟรีสาธารณะ ซึ่ง **ห้ามใช้กับแอปที่เปิดจริง/หารายได้** และอาจถูกบล็อกได้ทุกเมื่อ:

| บริการที่ใช้ตอนนี้ | กติกา | 
|---|---|
| OSRM demo / FOSSGIS (เส้นทาง) | ไม่เกิน **1 คำขอ/วินาที** รวมทุกผู้ใช้ (ทุกคำขอออกจากเซิร์ฟเวอร์เราที่เดียว), ห้ามใช้เชิงพาณิชย์/ใช้หนัก |
| tile.openstreetmap.org (ภาพแผนที่) | ไม่มีตัวเลขกำหนด แต่บล็อกได้โดยไม่แจ้ง, เตือนแอปเชิงพาณิชย์ |

**ต้องเปลี่ยนเมื่อ (ข้อใดข้อหนึ่ง):** เปิดให้คนทั่วไปใช้ / มีรายได้, หรือคำขอเส้นทางช่วงคนเยอะเกิน ~1 ครั้งทุก 2 วินาที (ประมาณผู้ใช้ 1,000–2,000 คน/วัน), หรือเริ่มเจอ error ถูกบล็อก
(ถ้าเซิร์ฟเวอร์เส้นทางล่ม แอปยังใช้ค่าประมาณระยะทางแทนได้ แต่ถ้าภาพแผนที่ถูกบล็อก แผนที่จะว่าง)

### เส้นทาง — ตัดสินใจแล้ว: ตั้ง OSRM เองบน Oracle Cloud "Always Free" ($0)

- เครื่องฟรี: 2 CPU (Ampere A1), RAM 12 GB, ดิสก์ 200 GB, ส่งข้อมูลออก 10 TB/เดือน — OSRM ประเทศไทยใช้ RAM แค่ ~1–2 GB ต่อโหมด จึงรันได้ทั้ง car และ foot (และวางตัวแอป Traval ไว้เครื่องเดียวกันได้)
- ข้อมูล: ไฟล์ `thailand-latest.osm.pbf` จาก Geofabrik (ไฟล์เดียวกับที่ใช้ทำรายชื่อสถานที่) อัปเดตเดือนละครั้ง
- ติดตั้งด้วย Docker image `osrm/osrm-backend` (ขั้นตอน extract → partition → customize → routed) แยกโปรไฟล์ `car.lua` และ `foot.lua`
- **โค้ดไม่ต้องแก้** — แค่ตั้งค่า `TRAVAL_OSRM_CAR` / `TRAVAL_OSRM_FOOT` ตามข้อ 4
- ข้อควรระวัง: Oracle อาจเรียกคืนเครื่องฟรีที่แทบไม่ได้ใช้งาน 7 วัน (ใช้งานต่ำกว่า 20%), สมัครต้องใช้บัตรเพื่อยืนยันตัวตน, บางภูมิภาคเครื่องฟรีอาจเต็ม

### ภาพแผนที่ — เลือกภายหลัง ระหว่าง D หรือ E

| | D. OpenFreeMap | E. ไฟล์แผนที่ของเราเอง (Protomaps) |
|---|---|---|
| ค่าใช้จ่าย | $0, ไม่ต้องมี key | $0 (วางบนเครื่อง Oracle เดียวกัน) |
| ขีดจำกัด | ไม่จำกัดจำนวนครั้ง, ใช้เชิงพาณิชย์ได้ | ตามเครื่องของเรา (10 TB/เดือน เหลือเฟือ) |
| งานที่ต้องทำ | ไม่มีเซิร์ฟเวอร์ให้ดูแล | ทำไฟล์ `.pmtiles` ประเทศไทย อัปเดตเดือนละครั้ง |
| ความเสี่ยง | ไม่มี SLA — ถ้าเขาล่มเราก็ล่ม | เราดูแลเองทั้งหมด |

**ทั้งสองแบบเป็นแผนที่แบบ vector** — แผนที่ปัจจุบันของ Moo วาดจากรูปภาพ tile (`<img>`) จึงต้องเปลี่ยนไปใช้ไลบรารี **MapLibre GL JS** (ฟรี, ไม่มี dependency ฝั่งเซิร์ฟเวอร์) — **ต้องคุยกับ Moo ก่อน** เพราะเป็นส่วนของ Moo
ข้อดีเพิ่ม: ซูมลื่นกว่า, ภาพคมทุกระดับ, ปรับสีแผนที่ให้เข้ากับแอปได้, ป้ายชื่อภาษาไทย/อังกฤษสลับได้

ระหว่างนี้ยังใช้ `MAP_TILE_URL` (tile.openstreetmap.org) ใน `frontend/traveler/app.js` ได้ตามเดิมสำหรับการพัฒนา/ทดสอบ
