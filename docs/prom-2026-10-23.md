## 1. วัตถุประสงค์ของการดำเนินงาน

ต่อยอดและยกระดับระบบ Traval จากหน้าต้นแบบการนำเสนอ (Showcase Prototypes) ของ Tommy และ Nine ให้กลายเป็น **"ระบบที่ใช้งานได้จริง (Fully Functional Application)"** เชื่อมโยงทุกบทบาทเข้ากับ Backend API และฐานข้อมูล SQLite จริง โดยทำส่วนของ Authentication และ Core Integration นำไปก่อนเพื่อให้เพื่อนร่วมทีมสามารถนำไปใช้งานต่อได้ทันที:
1. **Full Functional Integration:** ไม่ใช่แค่หน้าม็อคอัพ UI อีกต่อไป ทุกปุ่ม ทุกฟอร์ม และทุก Action เชื่อมต่อกับ SQLite Backend ผ่าน REST API
2. **Multi-Provider Authentication:** จัดทำระบบยืนยันตัวตนครบวงจร ทั้ง Google Login, Facebook Login, Phone OTP Verification และ Email/Password พร้อมสอดคล้องกับข้อกำหนด PDPA
3. **Admin Experience & Moderation:** แก้ไขปัญหาการเข้าสู่ระบบของแอดมินที่เคยใช้งานยาก ทำระบบรีเซ็ตรหัสผ่านและ Auto-auth อำนวยความสะดวก พร้อมเชื่อมระบบตรวจสอบร้านค้า SME และจุดเสี่ยงอันตราย (Safety Reports)
4. **Local SME Business Portal:** เชื่อมระบบลงทะเบียนร้านค้าชุมชน 3 ขั้นตอน (3-Step Wizard) และระบบแก้ไขเรื่องเล่าวิถีชุมชน (Local Story TH/EN) ให้บันทึกลงฐานข้อมูลจริง
5. **Zero External Dependencies:** ยึดมาตรฐาน Node.js Native Runtime (>= 22.14 LTS) และ `node:sqlite` เท่านั้น ไม่มีการติดตั้ง 3rd-party library ใดๆ เพิ่มเติม

## 2. รายละเอียดงานที่ทำเสร็จสมบูรณ์ (Changelog & Deliverables)

### 2.1 ระบบยืนยันตัวตนและฐานข้อมูลผู้ใช้ (Authentication & Identity Core)
- **การปรับปรุง Schema (`backend/server.js`):**
  - เพิ่มฟิลด์ `provider`, `provider_id`, `phone`, `avatar_url` ในตาราง `users` (Additive Migration ไม่กระทบข้อมูลเดิม)
  - สร้างตาราง `phone_otps` (phone TEXT PK, otp_hash, expires_at, attempts, created_at)
- **API Endpoints ใหม่:**
  - `POST /api/auth/social`: รองรับ Google Login และ Facebook Login เชื่อมโยงบัญชีตามอีเมลหรือสร้างบัญชีใหม่ที่ผ่านการยืนยันแล้วอัตโนมัติ พร้อมออก Session Token
  - `POST /api/auth/phone/otp-request`: ส่งรหัส OTP 6 หลัก อายุ 5 นาที พร้อม Return รหัส OTP ใน Response เพื่อความสะดวกรวดเร็วในการทดสอบระบบบนเครื่อง Local
  - `POST /api/auth/phone/otp-verify`: ตรวจสอบรหัส OTP และล็อกอิน/สร้างบัญชีด้วยเบอร์โทรศัพท์
  - `POST /api/auth/logout-all`: เพิกถอน Session ทั้งหมดของบัญชีผู้ใช้ในทุกอุปกรณ์ (Logout All Devices)
  - ปรับนโยบายรหัสผ่าน: ผู้ใช้งานทั่วไปใช้รหัสผ่านขั้นต่ำ 8 ตัวอักษร (จากเดิม 12 ตัวอักษร) ส่วนแอดมินยังคงความปลอดภัยระดับสูงที่ 12 ตัวอักษรตามมาตรฐานความมั่นคงปลอดภัย
- **การเชื่อมต่อหน้าเว็บ Auth:**
  - [login.html](file:///c:/Users/promb/Desktop/unfold-travel/frontend/auth/login.html): เพิ่ม Interactive Modal สำหรับ Google Login, Facebook Login และ Phone OTP Login มีการกรอกรหัสยืนยัน 6 หลักและเข้าสู่ระบบจริง
  - [register.html](file:///c:/Users/promb/Desktop/unfold-travel/frontend/auth/register.html): เชื่อมต่อ API ลงทะเบียนผู้ใช้จริงด้วยรหัสผ่าน 8 ตัวอักษรขึ้นไป
  - [profile.html](file:///c:/Users/promb/Desktop/unfold-travel/frontend/auth/profile.html): แสดงข้อมูลผู้ใช้จริงจาก `/api/auth/me`, ปุ่มออกจากระบบทุกอุปกรณ์ (`/api/auth/logout-all`) และระบบขอลบบัญชีถาวรตามสิทธิ PDPA (`DELETE /api/me/account`)
  - [app.js](file:///c:/Users/promb/Desktop/unfold-travel/frontend/traveler/app.js): เพิ่มปุ่มล็อกอินด้วย Google, Facebook, และเบอร์โทรศัพท์ใน Traveler Profile Sheet

### 2.2 ระบบแอดมินและการตรวจสอบเนื้อหา ([admin-showcase.html](file:///c:/Users/promb/Desktop/unfold-travel/frontend/admin/admin-showcase.html))
- **Dashboard Overview:** เชื่อมต่อกับ `GET /api/admin/stats` แสดงตัวเลขจริงของสถานที่ท่องเที่ยว, จำนวนผู้ใช้, ร้านค้า SME และจำนวนงานที่รอตรวจสอบ
- **สัดส่วนสถานที่ตามภูมิภาค (Coverage):** คำนวณเปอร์เซ็นต์และจำนวนจริงจากฐานข้อมูลสถานที่ (`GET /api/places`) แบ่งตามภาคเหนือ ภาคกลาง ภาคใต้ และภาคอีสาน
- **ตรวจสอบร้านค้าชุมชน (SME Verification):** ดึงคำขอจริงจาก `GET /api/admin/business-submissions?status=all` เมื่อกดปุ่ม "อนุมัติ" หรือ "ปฏิเสธ" จะส่งคำสั่งไปที่ `POST /api/admin/business-submissions/:id/decision` และอัปเดตสถานะในฐานข้อมูลทันที
- **ตรวจสอบจุดเสี่ยงและเหตุหลอกลวง (Safety & Scam Reports):** ดึงรายงานจาก `GET /api/admin/safety-reports?status=all` และส่งคำสั่งตรวจสอบ `PATCH /api/admin/safety-reports/:id` พร้อมบันทึกคำแนะนำ Admin Note ลง SQLite ทันที
- **SME Performance Analytics:** ดึงข้อมูลสถิติ Conversion จาก `GET /api/admin/sme-stats` (Impressions, Views, Directions, Trip Adds) และเรนเดอร์ตารางร้านค้ายอดนิยมอัตโนมัติ
- **ระบบช่วยเหลือการเข้าสู่ระบบของแอดมิน:** มีระบบ Auto-auth บนเครื่อง Local และสคริปต์ [RESET-ADMIN-PASSWORD.cmd](file:///c:/Users/promb/Desktop/unfold-travel/RESET-ADMIN-PASSWORD.cmd) สำหรับรีเซ็ตรหัสผ่านแอดมินเป็น `Admin@12345678` ได้ทันทีด้วยคลิกเดียว

### 2.3 ระบบร้านค้าชุมชน ([business-showcase.html](file:///c:/Users/promb/Desktop/unfold-travel/frontend/business/business-showcase.html))
- **ภาพรวมร้านค้า (Overview):** เชื่อมกับ `GET /api/business/me` แสดงชื่อเจ้าของร้าน, ป้ายสถานะการยืนยันตัวตน, ตัวเลขสถิติ และรายการร้านค้าจริงที่อยู่ในการดูแล
- **3-Step Onboarding Wizard (สมัครลงทะเบียนร้านค้า):**
  - Step 1: ข้อมูลพื้นฐานร้าน (ชื่อ TH/EN, หมวดหมู่ SME, เบอร์โทร, LINE)
  - Step 2: พิกัด GPS (Latitude, Longitude, ที่อยู่/จุดสังเกต)
  - Step 3: เอกสารยืนยันสิทธิ์ความเป็นเจ้าของ
  - เมื่อกดยื่นแบบฟอร์ม ระบบจะสร้างโปรไฟล์ธุรกิจผ่าน `POST /api/business/register` และส่งข้อเสนอสถานที่ผ่าน `POST /api/business/submissions` เข้าสู่คิวรอแอดมินอนุมัติจริง พร้อมเพิ่มการ์ด Pending ให้เห็นบนหน้าเว็บทันที
- **โปรไฟล์ร้าน & Local Story:** เชื่อมต่อปุ่มบันทึกกับ `PATCH /api/business/me` สำหรับแก้ไขเรื่องเล่าวิถีชุมชนภาษาไทยและภาษาอังกฤษเพื่อโปรโมตให้นักท่องเที่ยวได้อ่าน
- **แพ็กเกจโปรโมต (SME Boost):** รองรับการกดเลือกซื้อแพ็กเกจโฆษณา (Category Pin, Nearby Top Rank, Spotlight Hero) พร้อมบันทึกคำขอยื่นต่อแอดมิน
