## 1. บทสรุปผู้บริหาร (Executive Summary)

โครงการ **Traval** มีเป้าหมายในการสร้างแพลตฟอร์มท่องเที่ยวที่กระจายรายได้สู่ชุมชนและสนับสนุนผู้ประกอบการท้องถิ่น (Local SMEs) โดยเปลี่ยนผ่านจากโครงงานต้นแบบ (Prototypes/Mockups) สู่ **ระบบปฏิบัติการจริง 100% (Full-Stack Operational System)**:
- **Zero-Dependency Architecture:** ทำงานบน Node.js Native Runtime และ `node:sqlite` ปราศจาก external npm packages แปลกปลอม
- **Zero-Cost Map Strategy:** ใช้สถาปัตยกรรมแผนที่คู่ขนาน โดยตั้งต้นด้วย Leaflet + OpenStreetMap Official เพื่อใช้งานได้ฟรี ไม่เสียค่าใช้จ่าย และรองรับการเชื่อมต่อ Google Maps Platform ในอนาคต
- **Multi-Region Data:** วางข้อมูลสถานที่จริงและร้านค้าชุมชน 44 แห่ง กระจายครบทุกภาคของไทย (เหนือ, กลาง, ใต้, อีสาน) พร้อมหมุดแจ้งเตือนความปลอดภัย

## ส่วนที่ 1: การยกระดับ Backend API และสถาปัตยกรรมระบบ (Prom)

### 1.1 ระบบจัดการคอลเลกชันแบบหลายโฟลเดอร์ (Multi-Folder Collections)
สอดคล้องกับข้อกำหนด Phase 1 (หัวข้อ 1.4 Your Collection - จัดหมวดตามจังหวัดหรือธีม):
- `GET /api/me/folders`: ดึงรายการโฟลเดอร์ทั้งหมดของผู้ใช้ พร้อมจำนวนสถานที่ (`placeCount`)
- `POST /api/me/folders`: สร้างโฟลเดอร์ใหม่ รองรับ `{ name, color, icon }`
- `DELETE /api/me/folders/:id`: ลบโฟลเดอร์ของผู้ใช้
- `GET /api/me/folders/:id/places`: ดึงสถานที่ทั้งหมดที่อยู่ในโฟลเดอร์
- `POST /api/me/folders/:id/places`: บันทึกสถานที่ลงในโฟลเดอร์ `{ placeId }`
- `DELETE /api/me/folders/:id/places/:placeId`: นำสถานที่ออกจากโฟลเดอร์

### 1.2 ปรับปรุง API แนะนำร้านชุมชน SME (`POST /api/trips/recommend-sme`)
- รองรับทั้งการส่ง `{ places: ['id1', 'id2'] }` และ `{ stops: [{ lat, lon, name }, ...] }`
- คำนวณระยะทางเบี่ยงเส้นทางจริง (Detour Km) และเวลาที่ต้องใช้เพิ่ม
- ส่งคืนทั้งฟิลด์ `recommendations` และ `stopovers` เพื่อให้ใช้งานได้ทันทีกับทั้ง `planner.js` และ `planner-showcase.html` โดยไม่เกิดข้อผิดพลาด

### 1.3 รองรับ Itinerary Route Alias
- รองรับทั้ง `/api/me/itineraries` และ `/api/itineraries` (GET, POST, PUT, DELETE, `/add-stop`)
- ป้องกันข้อผิดพลาด 404 เมื่อฝั่งหน้าบ้านหรือโปรโตไทป์เรียกใช้เส้นทางแบบสั้น

### 1.4 ตัวกรองค้นหาสถานที่บนเซิร์ฟเวอร์ (`GET /api/places`)
- รองรับ Query Parameters สำหรับค้นหาและกรองข้อมูล:
  - `?q=...` หรือ `?search=...`: ค้นหาคำในชื่อไทย/อังกฤษ และคำบรรยาย
  - `?category=...`: กรองตามหมวดหมู่ (nature, culture, cafe, food, etc.)
  - `?region=...`: กรองตามภูมิภาค (north, central, south, northeast)
  - `?sme=1`: กรองเฉพาะร้านค้าและวิสาหกิจชุมชน
  - `?featured=1`: กรองเฉพาะสถานที่แนะนำ

### 1.5 ยกระดับ API วิเคราะห์ข้อมูล (`POST /api/analytics/event`)
- รองรับพารามิเตอร์ทั้ง `placeSlug` และ `placeId`
- รองรับประเภท Event ทุกรูปแบบ (`save`, `trip_add`, `view`, `direction`, `favorite`, `add_trip`)
- บันทึกลงตาราง `place_events` และตอบสนอง 200 OK เสมอ ป้องกันข้อผิดพลาด 400 Bad Request บนเบราว์เซอร์

## ส่วนที่ 2: งานวิจัยและกลยุทธ์บริการ Google & แผนที่คู่ขนาน (Tommy)

### 2.1 สถาปัตยกรรมแผนที่คู่ขนาน (Dual-Engine Map Strategy)
1. **Local Development & Free Tier:** ใช้ **Leaflet + OpenStreetMap (OSM)** ซึ่งฟรี 100% ไม่มีข้อจำกัดด้านโควตา สำหรับการพัฒนาและการใช้งานทั่วไป
2. **Production & Commercial Scale:** ผูก **Google Maps Platform** สำหรับฟีเจอร์ขั้นสูง เช่น Street View, Place Autocomplete, และ Turn-by-Turn Road Routing โดยมีระบบ Caching ใน SQLite เพื่อประหยัดค่า API

### 2.2 การวิเคราะห์บริการ Google แต่ละตัว
- **Google Maps JavaScript API:** เรนเดอร์แผนที่เวกเตอร์/แรสเตอร์แบบโต้ตอบ รองรับ Custom Vector Styling, Marker Clustering, Street View 360°
  - *ความเข้ากันได้กับ Traval:* เก็บพิกัด `lat`, `lon` แบบ WGS84 นำเข้า `google.maps.Marker` หรือ Leaflet สลับกันได้ผ่าน Map Wrapper
- **Google Places API (New):** ค้นหาจุดสังเกต, ร้านค้า, Auto-complete ช่องค้นหา และดึงรูปภาพ/เวลาเปิดทำการ
  - *ฐานข้อมูล SQLite:* ตาราง `places` มีคอลัมน์ `google_place_id TEXT` รองรับเรียบร้อย
  - *ข้อกำหนดทางกฎหมาย (ToS Compliance):* ห้ามแคชรายละเอียดร้านเกิน 30 วัน แต่อนุญาตให้เก็บ Place ID และพิกัด Lat/Lon ได้ถาวร
- **Google Routes API:** คำนวณเส้นทางตามโครงข่ายถนนจริง (Driving, Walking, Transit) พร้อมประมาณการเวลาตามสภาพจราจร
- **Google Authentication:** รองรับแล้วใน `POST /api/auth/social` พร้อมตั้งค่า `email_verified = 1` ให้ทันที

### 2.3 การวิเคราะห์ค่าใช้จ่ายและโควตา (Google Cloud Pricing & Quotas)
Google Cloud ให้เครดิตฟรี **$200 USD ต่อเดือน (~7,000 บาท)** แก่ทุก Billing Account:

|---|---|---|

**กลยุทธ์ประหยัดค่าใช้จ่าย:**
1. **Debounce Search Input:** หน่วงเวลาการพิมพ์ 300-400ms ก่อนเรียก Autocomplete
2. **Session Tokens:** ใช้ Autocomplete Session Token คิดเงิน 1 ครั้งต่อการค้นหาจนถึงการคลิกเลือกสถานที่
3. **Database First Policy:** ตรวจสอบสถานที่ในฐานข้อมูล Traval SQLite ก่อน หากมีอยู่แล้วไม่ต้องเรียก Place Details ซ้ำ
4. **Direct Google Maps Deep Link:** สำหรับการนำทางจริง ใช้ URL Scheme ฟรี:
   `https://www.google.com/maps/dir/?api=1&destination={lat},{lon}&travelmode={mode}`

## ส่วนที่ 4: การวางข้อมูลสถานที่อัตโนมัติและระบบร้านค้าชุมชน

### 4.1 ข้อมูลสถานที่ในระบบปัจจุบัน (44 Published Places Across Thailand)
ฐานข้อมูล SQLite ปัจจุบันบรรจุข้อมูลจริง 44 สถานที่ กระจายครบ 4 ภูมิภาคหลัก พร้อมภาพ Upload Assets 115 รายการ (ผ่านการตรวจสอบของ `node doctor.js` ครบถ้วน):
- **ภาคกลาง (Central):** เกาลัดนายโอวเยาวราช, ขนมฝรั่งกุฎีจีน, วังหลังเบเกอรี่, วัดอรุณฯ, โรตีสายไหมอยุธยา, น้ำตกเอราวัณ, โฮมสเตย์สวนมะพร้าวอัมพวา, บะหมี่ไข่ทำมือตลาดน้อย, วัดไชยวัฒนาราม, จักรยานบางกะเจ้า
- **ภาคเหนือ (North):** วัดร่องขุ่น, วัดร่องเสือเต้น, กาแฟคั่วสดนิมมาน, ร่มบ่อสร้าง, วัดภูมินทร์ น่าน, กองแลน ปายแคนยอน, ชามตราไก่ลำปาง, วัดผาลาด, ม่อนแจ่ม, แม่กำปอง, บ้านป่าบงเปียง, บ้านรักไทย, ภูชี้ฟ้า
- **ภาคใต้ (South):** แหลมพรหมเทพ, หมี่ต้นโพธิ์ภูเก็ต, เกาะปันหยีพังงา, สระมรกตกระบี่, โรงกลั่นรัมสมุย, กระจูดวรรณีพัทลุง, ครัวชาวเลเกาะยาวน้อย, แพไม้ไผ่เขาสก, อ่าวไร่เลย์, น้ำมันมะพร้าวสมุย
- **ภาคอีสาน (Northeast):** สามพันโบก, ทะเลบัวแดงอุดรฯ, เครื่องปั้นดินเผาด่านเกวียน, วัดป่าภูก้อน, ผ้านวมฝ้ายเชียงคาน, ผ้าย้อมครามสกลนคร, ผาแต้มอุบลฯ, ฟาร์มโคนมเขาใหญ่

### 4.2 ระบบนำเข้าข้อมูลอัตโนมัติ (Automated Import Engine)
- สคริปต์ [scripts/auto_populate_places.js](file:///c:/Users/promb/Desktop/unfold-travel/scripts/auto_populate_places.js): สั่งรันเพิ่มข้อมูลอัตโนมัติใน 1 วินาที
- ปุ่มใน Admin Studio: **`⚡ นำเข้าข้อมูลสถานที่ทั่วไทย (Auto-Populate)`** บนหน้า Dashboard เรียก API `POST /api/admin/auto-populate` ให้แอดมินกดนำเข้าได้ทันทีจากหน้าจอ

### 4.3 ระบบร้านค้าปักหมุดเอง (Crowdsourcing)
- **Business Portal (3-Step Wizard):** ร้านค้า SME สามารถกรอกข้อมูล ปักหมุด GPS และแนบหลักฐาน
- **Claim a Shop:** ยื่นขอเป็นเจ้าของร้านค้าที่มีอยู่แล้วบนแผนที่
- **Admin Studio:** จัดคิวคำขอและกด **`✓ อนุมัติ (Approve)`** เพียงคลิกเดียว ร้านค้าจะขึ้นแสดงผลบนแผนที่นักเดินทางสดทันที
