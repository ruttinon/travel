## Nine / ruttinon — `frontend/business/business.html`

**ปัญหาเดิม (QA #1):** ฟอร์ม "สมัครลงทะเบียนร้าน" ขึ้นว่าส่งสำเร็จเสมอ แต่ไม่มีอะไรถึงแอดมิน — ส่งประเภทธุรกิจที่เซิร์ฟเวอร์ไม่รับ (`cafe`, `craft`), อีเมลปลอม `merchant@local.th`, ไม่อัปโหลดรูป, ไม่กด "ส่ง", ภาค (region) เป็นคำว่า "เชียงใหม่", ซ่อน error ทุกอย่าง · `saveProfile()` และฟอร์มอ้างสิทธิ์ก็แค่โชว์ข้อความสำเร็จ · แท็บ "อ้างสิทธิ์ร้าน" ไม่เคยแสดง (แท็บโปรไฟล์ไม่ได้ปิด `</section>` แท็บอ้างสิทธิ์เลยซ้อนอยู่ข้างใน) · `loadClaimablePlaces()` ไม่ถูกเรียก

**กฎของเซิร์ฟเวอร์ที่หน้าเว็บต้องทำตาม (ไม่ได้แก้เซิร์ฟเวอร์):**
1. `POST /api/business/register` → โปรไฟล์ธุรกิจสถานะ `pending` · `type` ต้องเป็น `food` / `stay` / `experience` / `other`
2. ธุรกิจต้อง `approved` โดยแอดมิน **และ** อีเมลบัญชีต้องยืนยันแล้ว ก่อนอัปโหลดรูปหรือเสนอร้าน (บัญชี Google ยืนยันให้อัตโนมัติ)
3. `POST /api/business/uploads` (รูป, บังคับ) → `POST /api/business/submissions` (ได้ `draft`) → `POST /api/business/submissions/:id/submit` (ได้ `pending` ถึงแอดมิน)
4. หมวดสถานที่ (`category`) ต้องเป็น `nature` / `food` / `stay` / `culture` · ภาค (`region`) ต้องเป็น `north` / `south` / `central` / `northeast` / `east` / `west`

**เปลี่ยนอะไร:**
- ลบค่าตัวอย่างที่กรอกไว้ล่วงหน้า (แม่กำปอง, 081-234-5678 ฯลฯ) — เหลือแค่ placeholder
- เพิ่ม `#wizStatus` บนฟอร์ม: บอกสถานะจริง (ยังไม่ล็อกอิน / ยังไม่มีธุรกิจ / รอแอดมิน / ถูกปฏิเสธ / ยังไม่ยืนยันอีเมล + ปุ่มส่งอีเมลอีกครั้ง / พร้อมส่ง)
- อัปโหลดรูปจริง: `<input type="file" id="wizPhoto">` + `onWizPhotoChosen()` (JPG/PNG/WebP ≤ 5 MB, มีภาพตัวอย่าง)
- ขั้นตอนเอกสาร: เอาการอัปโหลดปลอมออก (เซิร์ฟเวอร์ยังไม่มีที่เก็บเอกสาร) เขียนว่าแอดมินจะติดต่อขอดู · ช่องยืนยันความเป็นเจ้าของ `#wizConsent` ต้องติ๊ก
- `submitWizard()` เขียนใหม่ตามกฎ 1–4: ส่งครั้งแรก = สร้างโปรไฟล์ธุรกิจ (`WIZ_TYPE`: cafe→food, food→food, stay→stay, craft→experience; อีเมลติดต่อ = อีเมลบัญชี) แล้วบอกให้รอแอดมิน · ข้อมูลร้านเก็บในเครื่อง (`localStorage` คีย์ `traval-business-wizard-draft`, `saveWizardDraft()` / `restoreWizardDraft()`) · หลังอนุมัติ กดส่งอีกครั้ง = อัปโหลดรูป → เสนอร้าน → ส่งถึงแอดมิน (`WIZ_CATEGORY`: cafe→food, craft→culture …, ภาคหาจากสถานที่ OSM ใกล้หมุด `regionForPosition()`) · error แสดงตามจริง
- `saveProfile()` ส่งโปรไฟล์ครบทุกช่องที่เซิร์ฟเวอร์ต้องการ (`name`, `type`, `contactEmail`, `phone`, `website`, `description`) · `fillProfileFromServer()` เติมชื่อร้าน/เรื่องเล่าจากเซิร์ฟเวอร์
- `submitClaimRequest()` ส่งคำขอ `action:'claim'` จริง + กด submit · เรียก `loadClaimablePlaces()` ตอนโหลดหน้า · ปิด `</section>` ของแท็บโปรไฟล์ให้ถูกที่
- ข้อความจากเซิร์ฟเวอร์ใส่ผ่าน `escHtml()` (ชื่อร้านมี `<b>` ก็แสดงเป็นตัวอักษร)
- CSS มือถือ (`@media (max-width: 860px)`): เมนูด้านข้างกลายเป็นแถบเลื่อนด้านบน เนื้อหาเต็มจอ

**ถ้าจะแก้ต่อ:** อย่ากลับไปใช้ `.catch(() => {})` แล้วโชว์ข้อความสำเร็จ — ผู้ใช้ต้องเห็น error จริง · ยังเป็นข้อมูลตัวอย่างตายตัว: KPI ภาพรวม (2 / 1 / 1 / 1,120), ตารางแคมเปญ, ชิป "Verified", "สวัสดี คุณสมชาย" ก่อนโหลดเสร็จ, เวลาเปิด-ปิด/ราคา/เรื่องเล่าภาษาอังกฤษในแท็บโปรไฟล์ (เซิร์ฟเวอร์เก็บในโปรไฟล์ธุรกิจแค่ชื่อ/โทร/คำอธิบาย) · ปุ่มซื้อแพ็กเกจยังไม่ส่งอะไร

- `SAMPLE_PLACES` ถูกรวมกับข้อมูลเซิร์ฟเวอร์ → แม่กำปองซ้ำ 2 อัน, มีสถานที่ที่เซิร์ฟเวอร์ไม่รู้จัก · ผู้ใช้ใหม่มี "Saved 2" ตั้งแต่แรก
- มี `sw.js` แต่ไม่เคย `register()` → ใช้ออฟไลน์ไม่ได้
- แผ่นรายละเอียดบนแผนที่ไม่มีปุ่มเพิ่มในทริป · หัวใจสีขาวบนพื้นขาว
- `assets/1.png`–`3.png` จริง ๆ เป็นไฟล์ JPEG

**เปลี่ยนอะไร:**
- `state.saved` / `state.trip` ตอนเริ่ม: เก็บทุก id ไว้ก่อน (ไม่กรอง) และเริ่มว่าง · หลัง `initRealData()` ได้ข้อมูลจริง ค่อยตัด id ที่ไม่มีอยู่จริงออก
- `initRealData()`: `PLACES = realPlaces` (เซิร์ฟเวอร์อย่างเดียว, ทุกอันมี `live:true`) · `SAMPLE_PLACES` ใช้เฉพาะตอนต่อเซิร์ฟเวอร์ไม่ได้
- ท้ายไฟล์: `const placesReady = initRealData()` แล้วค่อย `refreshSession()` · `loadAccountCollections()` รอ `placesReady` แล้ว **รวมรายการของผู้เยี่ยมชมเข้าบัญชี** (เฉพาะสถานที่ที่เซิร์ฟเวอร์รู้จัก) อัปโหลด แล้วล้างรายการผู้เยี่ยมชม
- ลงทะเบียน service worker (`navigator.serviceWorker.register('/sw.js')`, https หรือ localhost) · `sw.js`: ชื่อ cache ใหม่ `unfold-v2.7-offline-1`, ออฟไลน์เปิด `/?…#trip` ได้, เพิ่ม `google-login.js` · **ถ้าเพิ่ม/ลบไฟล์ใน `ASSETS` ให้เปลี่ยนชื่อ `CACHE`**
- แผ่นรายละเอียดบนแผนที่: ปุ่ม **"+ ทริป"** (`data-action="trip-toggle"`) และหัวใจสีเข้มเมื่อยังไม่บันทึก
- `assets/1.png`→`1.jpg` (และ 2, 3 ทั้งใน `assets/` และ `frontend/traveler/assets/`) · `LANDING_SLIDES` ชี้ `.jpg`
