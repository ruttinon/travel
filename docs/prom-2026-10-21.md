## 2. สิ่งที่ได้ทำไปทั้งหมด (Changelog & Deliverables)

### 2.1 โครงสร้างฐานข้อมูลและการอัปเกรด Schema (`server.js`)
1. **เพิ่มฟิลด์ Local SME ลงตาราง `places`:**
   - `is_sme` (INTEGER): ระบุร้านค้าชุมชน / SME ท้องถิ่น
   - `sme_type` (TEXT): ประเภทร้าน SME เช่น food, cafe, market, handicraft, local experience
   - `spotlight_badge` (TEXT): ป้ายกำกับพิเศษ เช่น 'Local Pick', 'Hidden Gem', 'New Local Shop'
   - `local_story_th` / `local_story_en` (TEXT): เรื่องราวความเป็นมาและเอกลักษณ์ของร้าน
   - `contact_phone`, `contact_website`, `contact_line` (TEXT): ข้อมูลติดต่อของร้าน
   - `opening_hours_json` (TEXT): ข้อมูลเวลาเปิด-ปิดร้าน
   - `google_place_id` (TEXT): รองรับการผูกกับ Google Place ID ในอนาคต
   - `is_sponsored` (INTEGER): แยกความแตกต่างระหว่างร้านที่ซื้อพื้นที่โปรโมตกับผลลัพธ์ธรรมชาติ
2. **สร้างตาราง Travel Safety & Scam Reports:**
   - `travel_safety_reports`: รายงานจุดเสี่ยง / โก่งค่าโดยสาร / แท็กซี่ไม่กดมิเตอร์ / จุดอันตราย พร้อมสถานะ `pending`, `verified`, `rejected`, `resolved`
   - `safety_media`: จัดเก็บภาพถ่ายหลักฐานในโฟลเดอร์แยก `/safety-media/`
3. **สร้างตาราง Campaigns & Promotion Banners (CMS):**
   - `campaigns`: รองรับการจัดแคมเปญโปรโมตร้าน SME, Local Spotlight, วันที่เริ่ม-สิ้นสุด และลำดับ priority
4. **สร้างตาราง Place Events (Stateless SME Analytics):**
   - `place_events`: บันทึกสถิติ Performance ของร้าน SME (`view`, `direction`, `phone`, `website`, `favorite`, `add_trip`, `sme_impression`) แบบ Stateless ไม่เก็บข้อมูลส่วนตัวผู้ใช้ตามหลัก PDPA
5. **เพิ่มสถานะบัญชีและการลบบัญชี (PDPA Erasure):**
   - เพิ่ม `users.status` (`active` / `suspended`) ในตาราง `users`
   - เมื่อ Admin สั่งระงับบัญชี ผู้ใช้จะได้รับ HTTP 403 Forbidden ทันทีในทุก Endpoint

### 2.2 ระบบ API Endpoints ที่พัฒนาใหม่และเปิดให้บริการ

#### 1) หมวด Local SME & Around Me
- `GET /api/places/sme`: ค้นหาร้านค้า SME ตามประเภท, ภูมิภาค หรือร้าน Spotlight
- `GET /api/places/spotlight`: ดึงรายการร้านค้าท้องถิ่นแนะนำสำหรับแสดงในโซน Local Spotlight Rail
- `GET /api/places/nearby?localOnly=1`: ค้นหาสถานที่รอบตัว พร้อมตัวกรอง Local SME Only และกำหนดระยะรัศมี (300m, 500m, 1km, 3km, 5km)

#### 2) หมวด AI Travel Advisor & Auto Trip Planning (Section 1.1 & 1.5)
- `POST /api/ai/advisor`:
  - **Auto Trip Planning:** รับเงื่อนไขการจัดทริป (จังหวัด, จำนวนวัน 1-7 วัน, งบประมาณ, ผู้ร่วมเดินทาง, ความสนใจ, ยานพาหนะ, ความเร็วในการเที่ยว) -> จัดกลุ่มสถานที่ตามความใกล้เคียงทางภูมิศาสตร์ (Geographic Clustering) -> คำนวณระยะทางรวมและค่าใช้จ่าย (Taxi / Fuel / Transit / Food / Stay) -> แนะนำร้าน Local SME Stopovers ระหว่างทางแต่ละวัน -> ส่งคืนโครงสร้าง `groups` ที่สามารถกดบันทึกลง My Trips ได้ทันที
  - **Quick Walking Query:** รองรับคำถามค้นหาร้านในระยะเดินเท้า เช่น *"มีร้านอาหารท้องถิ่นในระยะเดิน 10 นาทีไหม"* โดยคำนวณจากพิกัด `userLat`, `userLon` ในระยะไม่เกิน 1.5 กม. พร้อมคำนวณเวลาเดินและระยะทางเป็นเมตร

#### 3) หมวด Trip Planning & Cost Estimation
- `GET /api/trips/estimate-cost`: คำนวณประมาณการค่าแท็กซี่มิเตอร์ตามสูตรจริงของกรมการขนส่ง และค่าน้ำมันรถยนต์ส่วนบุคคลตามระยะทาง (กม.)
- `POST /api/trips/recommend-sme`: แนะนำร้าน SME ที่เป็นจุดแวะพักระหว่างทางของทริป พร้อมคำนวณระยะเบี่ยงเส้นทาง (Detour km) และเวลาที่ต้องใช้เพิ่ม
- `POST /api/me/itineraries/:id/add-stop`: เพิ่มจุดแวะร้าน SME เข้าสู่วันเดินทางของทริปได้โดยตรง
- `GET /api/me/collections?populated=1`: ดึงข้อมูลสถานที่ที่บันทึกไว้ใน Saved/Trip Collections พร้อมข้อมูลสถานที่แบบเต็ม

#### 4) หมวด Travel Safety & Scam Reports
- `POST /api/safety/reports`: นักท่องเที่ยวแจ้งเตือนจุดเสี่ยง / รายงานเหตุการณ์ไม่ปลอดภัย (สถานะเริ่มต้น `pending`)
- `GET /api/safety/reports`: แสดงเฉพาะรายงานที่ผ่านการตรวจสอบแล้ว (`verified`) สำหรับนำไปปักหมุด Warning บนแผนที่
- `GET /api/me/safety-reports`: นักท่องเที่ยวตรวจดูประวัติและสถานะรายงานของตนเอง
- `POST /api/safety/upload`: อัปโหลดรูปภาพหลักฐานความปลอดภัย

#### 5) หมวด Spotlight, Campaigns & SME Analytics
- `GET /api/campaigns`: ดึงแบนเนอร์โปรโมตที่กำลังเผยแพร่อยู่บนเว็บไซต์
- `POST /api/analytics/event`: บันทึก Event การเข้าชมร้านค้า SME
- `GET /api/admin/sme-stats`: Admin ดูสถิติ Performance แยกตามร้าน SME (Impressions, Views, Directions, Trip Adds, Contacts)
- `GET / POST / PUT / DELETE /api/admin/campaigns`: Admin จัดการแคมเปญและแบนเนอร์โปรโมตร้าน SME

#### 6) หมวด Admin Moderation & User Management
- `GET /api/admin/users`: Admin ดูรายชื่อ ค้นหา ตรวจสอบจำนวนรีวิว ทริป และรายงานความปลอดภัย
- `PATCH /api/admin/users/:id/status`: Admin สั่งระงับ (`suspended`) หรือเปิดใช้งาน (`active`) บัญชีผู้ใช้ พร้อมบันทึก Audit Log
- `GET /api/admin/safety-reports`: Admin ตรวจสอบรายการรายงานความปลอดภัย
- `PATCH /api/admin/safety-reports/:id`: Admin อนุมัติ (`verified`) หรือปฏิเสธรายงานความปลอดภัย
- `GET /api/admin/stats`: สรุปตัวเลขสถิติรวมของระบบ (Users, Places, SMEs, Reviews, Itineraries, Categories)

#### 7) หมวด Account Erasure (PDPA Compliance)
- `DELETE /api/me/account`: ผู้ใช้งานขอลบบัญชีตนเองอย่างถาวร โดยระบบจะลบข้อมูลที่เชื่อมโยงแบบ Cascade อัตโนมัติและล้าง Session ทันที

### 2.3 การปรับปรุงความเสถียรและชุดคำสั่งระบบ (Tooling & Maintenance)
- **`backup.js`**: ปรับปรุงคำสั่ง Snapshot จาก `VACUUM INTO` แทนฟังก์ชันที่ไม่มีใน `node:sqlite` พร้อมรองรับการสำรองข้อมูลโฟลเดอร์ `safety-media/`
- **`restore.js`**: รองรับการกู้คืนข้อมูลโฟลเดอร์ `safety-media/`
- **`doctor.js` & `package.json`**: รองรับ Node.js ตั้งแต่ `v22.14` ขึ้นไป เพื่อให้สอดคล้องกับสภาพแวดล้อมที่ใช้งานจริง
- **Windows File Locking (EBUSY)**: แก้ไขการปิด `DatabaseSync` และรอ child process exit ในชุดทดสอบ ป้องกันปัญหาไฟล์ล็อกบน Windows
