## 2. ตรวจหน้าใหม่ของ Moo แบบผู้ใช้ครั้งแรก (มือถือ 390px + คอม, ธีมสว่าง + มืด)

| # | ปัญหา | แก้แล้ว |
|---|---|---|
| 1 | หัวเว็บบนมือถือมีปุ่ม 7 ปุ่มในจอกว้าง 390px **ปุ่มค้นหาจึงหลุดออกนอกจอ** | ปุ่มธีมเหลือปุ่มเดียว แสดงโหมดที่จะสลับไป (ป้ายบอกว่า "โหมดมืด" / "โหมดสว่าง") และซ่อนรูปโลกที่ปุ่มภาษา ตอนนี้ทุกปุ่มอยู่ในจอ |
| 2 | ปุ่ม ✕ ของ AI Advisor และหน้าต่างแจ้งเตือนภัย **เป็นสีขาวบนการ์ดสีขาว** จึงหาทางปิดไม่เจอ | ใช้สีตัวอักษรของธีม พร้อมพื้นปุ่ม |
| 3 | ปุ่มสไตล์ใน AI Advisor บนมือถือเป็น 4 คอลัมน์แคบ ๆ คำละบรรทัด | 2 คอลัมน์ |
| 4 | ปุ่ม "ดู" ในผลลัพธ์ AI ถูกบีบเป็นวงกลม อ่านแล้วเหมือน "ๆ" | "ดูสถานที่" ไม่ตัดคำ |
| 5 | คำใต้ไอคอนเมนูล่างเล็กมาก (9.5px) และ "ทริปของฉัน" ตัดเป็น 2 บรรทัด | 11px และใช้คำสั้น "ทริป" ในเมนู |
| 6 | หน้าแรกธีมสว่างบนมือถือ: ตัวหนังสือสีส้มในรูปสไลด์ทับหัวข้อ "ออกไปเจออะไรใหม่ ๆ" | พื้นขาวทึบขึ้นตรงช่วงหัวข้อ |
| 7 | ธีมมืด: ปุ่ม "EN" สีเทาบนพื้นดำ, การ์ดวิธีใช้เป็นสีขาว และหัวข้อเป็นสีเขียวเข้ม | ใช้สีของธีม |
| 8 | ส่วนที่ Tommy เพิ่ม (การ์ดลิงก์, วิธีใช้, ข้อความในหน้าว่าง) เป็นสีขาวตายตัว ไม่เปลี่ยนตามธีมมืด | ใช้ token สีของ Moo |
| 9 | `initRealData()` ถูกเรียก 2 ครั้งตอนเปิดแอป (โหลดข้อมูลซ้ำ) | เหลือครั้งเดียว |
| 10 | ช่องกรอก 3 จุดไม่มีป้ายกำกับสำหรับโปรแกรมอ่านหน้าจอ (ค้นหารายการที่บันทึก, เขียนรีวิว, ค้นหา AI) และปุ่มลูกศรบนแผนที่ไม่มีชื่อ | เพิ่ม `aria-label` |
| 11 | หน้าร้าน SME เป็นสีสว่างเสมอ แม้ผู้ใช้เลือกธีมมืดในแอป | ใช้ธีมตามที่ผู้ใช้เลือก |

## 3. ความปลอดภัย + พร้อมใช้จริง

- **Admin:** ข้อความจากผู้ใช้ทุกชนิดที่แสดงในหน้า Admin ตอนนี้ escape แล้ว (`adminEsc()`) ได้แก่ คำขอร้านค้า, รายงานจุดเสี่ยงจากนักท่องเที่ยว, ชื่อ/อีเมลผู้ใช้, สถิติร้าน และแคมเปญ ก่อนหน้านี้ใครก็ตามที่ส่งรายงานจุดเสี่ยงสามารถใส่สคริปต์ให้ไปรันในเบราว์เซอร์ของแอดมินได้
- **Admin "Recent Activity":** ดึงเหตุการณ์จริงจาก audit log (เดิมเป็นการ์ดตัวอย่าง 4 ใบ) และปุ่ม "ดูทั้งหมด" ไปหน้า audit
- **ปุ่ม Facebook / เบอร์โทร** ในหน้าเข้าสู่ระบบเป็นเดโมที่ใช้ได้แค่ในคอมของทีม บนเว็บจริงจะซ่อนเอง (เซิร์ฟเวอร์ส่ง `demoLogins:false`) จึงไม่มีปุ่มที่กดแล้วขึ้น error ให้ผู้ใช้เห็น

## 4. ทดสอบบนมือถือจริง: `RUN-PHONE-TEST.bat`

1. ดับเบิลคลิก `RUN-PHONE-TEST.bat` (ปิด `run.bat` ที่เปิดค้างไว้ก่อน)
2. ถ้า Windows ถามเรื่อง Firewall ให้กด **Allow** และเลือก **Private networks**
3. ในหน้าต่างดำ ดูบรรทัด `[PHONE TEST]` แล้วพิมพ์ที่อยู่ เช่น `http://192.168.1.34:5173/` ในเบราว์เซอร์ของมือถือ (มือถือต้องต่อ Wi-Fi เดียวกับคอม)
4. ในมือถือให้สมัครหรือเข้าสู่ระบบด้วย **อีเมล + รหัสผ่าน** เพราะ Google ไม่รับที่อยู่แบบ 192.168.x
5. ลิงก์ยืนยันอีเมลจะขึ้นในหน้าต่างดำ ให้เปิดลิงก์นั้นบนคอม
6. หน้า Admin ใช้ได้เฉพาะบนคอมที่รันเซิร์ฟเวอร์ ส่วนมือถือจะถูกปฏิเสธ

ใช้ใน Wi-Fi ที่บ้านเท่านั้น ห้ามเปิดแบบนี้ใน Wi-Fi สาธารณะ

## 5. ยังไม่ได้ทำ (ต้องตัดสินใจ หรือเป็นงานก่อน launch)

- หน้า Privacy / Terms (ลิงก์ยังเป็น `#`)
- หน้าโปรไฟล์: สวิตช์ Location / Safety และ Travel Style ยังไม่บันทึกค่า
- ก่อนขึ้นเซิร์ฟเวอร์จริง: โดเมน + HTTPS, ตั้งค่า Resend สำหรับอีเมล (`UNFOLD_RESEND_API_KEY`, `UNFOLD_EMAIL_FROM`, `UNFOLD_PUBLIC_URL`), เพิ่มชื่อโดเมนใน `checkHost`, ใส่ cookie `Secure` เมื่ออยู่หลัง proxy, OSRM บน Oracle, เลือกระหว่าง OpenFreeMap กับ Protomaps
- หน้าแรกมีที่ค้นหา 3 จุด ซ้ำซ้อน (ให้ Moo ตัดสินใจเรื่องดีไซน์)
